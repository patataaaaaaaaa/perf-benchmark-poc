# 2026-09-15：pyperf benchmark 生成可行性实验

## 研究问题

1. DeepSeek 能否根据真实 Python 函数源码生成可以执行的 `pyperf` benchmark？
2. 生成代码出错后，能否根据真实语法、导入和运行错误进行自动修复？

## 实验规模

- 项目：SymPy、mpmath
- 目标函数：10 个
- 每个函数独立生成：3 次
- 候选总数：30
- 每个候选最多自动修复：3 次

## 主要结果

| 指标 | 结果 |
|---|---:|
| 初次运行通过 | 21/30（70.0%） |
| 修复后运行通过 | 29/30（96.7%） |
| 人工确认语义正确 | 28/30（93.3%） |
| 需要自动修复 | 9/30 |
| 人工确认语义修复成功 | 7/9（77.8%） |

结果初步支持“LLM 可以生成并修复 pyperf benchmark”，但也发现了一份能够运行却错误使用计时 API 的假阳性。这说明必须把可执行性、目标语义和统计稳定性分开验证。

## 文件说明

- [`candidates.csv`](candidates.csv)：30 个候选的逐项记录。

## 结论边界

该实验使用本机 pyperf `--fast` 模式，目的是验证生成与修复能力，不能证明这些 benchmark 已经足够稳定，也不能推广到所有 Python 仓库。
